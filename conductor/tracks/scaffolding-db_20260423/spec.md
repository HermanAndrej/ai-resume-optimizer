## Summary

## Context

This is step 1–2 of the MVP build order. The app is a local personal tool — single Python process, FastAPI + HTMX, SQLite stored in the OS data directory. Zero-config startup is a hard requirement: clone → add key → install → run is the full setup.

## Technical Notes

- SQLite via stdlib `sqlite3` — no SQLAlchemy, no Alembic
- `row_factory = sqlite3.Row` for dict-like row access
- `PRAGMA foreign_keys = ON` on every connection
- `schema_version` table tracks applied migrations
- Profile row seeded on first run: `INSERT INTO profile (id) VALUES (1)`
- Server binds to `127.0.0.1` only — never `0.0.0.0`
